# Calculator App 🧮

A clean, responsive, and easy-to-use web-based calculator designed for performing everyday arithmetic calculations with a smooth user interface.

[Live Demo](https://omribrahim77.github.io/Calculator/)

---

## ✨ Features (المميزات)

- **Basic Arithmetic Operations:** Perform additions, subtractions, multiplications, and divisions effortlessly.
- **Clean Interface:** Minimalist and intuitive layout designed for a distraction-free user experience.
- **Responsive Design:** Works seamlessly across desktop computers, tablets, and mobile devices.
- **Real-time Display:** Instant calculation feedback right on the screen.

---

## 🚀 Built With (تقنيات البناء)

- **HTML5** for structure
- **CSS3** for styling and layout design
- **JavaScript (ES6+)** for logic handling and computational operations
